CLEANSWIFT PREMIUM CLEANING WEBSITE DEMO
========================================

এই ZIP-এ ১০টি পেজের responsive static website source আছে।

পেজগুলো:
1. Home — index.html
2. About — about.html
3. Services — services.html
4. House Cleaning — house-cleaning.html
5. Commercial Cleaning — commercial-cleaning.html
6. Deep Cleaning — deep-cleaning.html
7. Pricing — pricing.html
8. Booking / Get a Quote — booking.html
9. Blog — blog.html
10. Contact — contact.html

দ্রুত দেখার উপায়:
- ZIP Extract করুন।
- index.html ফাইল Chrome-এ খুলুন।
- Internet connection থাকলে Google Fonts ও Unsplash-এর ছবি লোড হবে।

Google AI Studio-তে ব্যবহার:
1. https://aistudio.google.com/ এ যান।
2. Build apps / Create app অপশন খুলুন।
3. নিচের PROMPT.txt-এর নির্দেশনা দিন এবং এই source files project-এ যোগ/পেস্ট করুন।
4. AI Studio-কে React/Vite project-এ convert করে preview ও deploy-ready করতে বলুন।

গুরুত্বপূর্ণ:
- CleanSwift একটি demo brand; এটি বাস্তব কোম্পানি নয়।
- ফোন, ইমেইল, দাম, রিভিউ এবং সেবার তথ্য sample content।
- Booking form এখন demo-only; কোনো বাস্তব ইমেইল/বুকিং পাঠায় না।
- Google Fonts ও Unsplash image ব্যবহারে internet দরকার।
- এটি static website source; সরাসরি WordPress theme বা production booking backend নয়।
- রেফারেন্স সাইটের exact copy নয়; inspired original design। বাস্তব ক্লায়েন্টের brand, content ও অনুমতি অনুযায়ী পরিবর্তন করুন।
